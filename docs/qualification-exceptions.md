# Qualification Exceptions

There are no accepted Phase 12 correctness or performance exceptions.

If a release-scale profile fails, record an entry before release:

```text
Candidate revision:
Profile and artifact:
Failed criterion:
Measured bottleneck:
Owner:
Follow-up issue:
Retest criterion:
Expiry:
```

Correctness failures, duplicate accepted moves, double assignments, invalid
terminal state, or unbounded state cannot be waived.
